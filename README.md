# AR Experience — 4 Revoluciones Industriales

Experiencia de Realidad Aumentada activada por imagen (póster), construida con [MindAR](https://github.com/hiukim/mind-ar-js) y [A-Frame](https://aframe.io/), 100% open source y gratuita. Al escanear el póster con la cámara del celular, aparecen modelos 3D representando cada una de las 4 revoluciones industriales.

## Cómo usarla

1. Abre [poster-ar.html](./poster-ar.html) desde un celular (o escanea el QR asociado).
2. Da permiso de cámara.
3. Apunta al póster impreso.
4. Los modelos 3D aparecen anclados sobre cada revolución industrial.
